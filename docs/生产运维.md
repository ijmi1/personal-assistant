# 生产运维

## 安全与观测

- 默认会话空闲 4 小时，支持通过 `ASSISTANT_SESSION_TIMEOUT` 调整。升级时可用 `ASSISTANT_ALLOW_LEGACY_PASSWORD=true` 短期兼容旧口令，更换后设回 `false`。
- HTTP 限流默认每分钟每账户 240、每匿名 IP 120、每登录 IP 10。AI 新建任务另按数据库计额。HTTP 计数在单实例内生效。可信代理默认仅回环接口，额外代理按实际地址配置 `ASSISTANT_TRUSTED_PROXY_REGEX`，代理须覆盖传入的转发头。
- 前端默认同源。确需跨源时，将完整的 `scheme://host[:port]` 填进 `ASSISTANT_CORS_ORIGINS`，多个值以逗号分隔。当前 `SameSite=Strict` Cookie 适用于同站访问。
- 登录后访问 `/swagger-ui/index.html` 或 `/v3/api-docs`。ECS 日志中，`assistant.access` 记录 API 路由模板、状态及耗时，`assistant.audit` 记录登录、启动时加载的口令策略、发送确认及最终处理状态。浏览器向本机上报固定错误类型。
- 配置自有 Collector 后设置 `ASSISTANT_OTLP_ENABLED=true` 和 `ASSISTANT_OTLP_ENDPOINT`。同一个 trace ID 可关联 HTTP、入队及后台执行。指标可按请求延迟、任务积压和检索缓存命中率设置告警。[Spring Boot Tracing](https://docs.spring.io/spring-boot/3.5/reference/actuator/tracing.html)
- Vault 或云密钥服务可由部署层将凭据注入只读目录，再设置 `SPRING_CONFIG_IMPORT=optional:configtree:/run/secrets/`。文件名使用变量名，例如 `ASSISTANT_SMTP_PASSWORD`，并移除同名环境变量。轮换时更新文件并重启。部署配置的修改记录由部署平台保留。[Spring Boot 配置树](https://docs.spring.io/spring-boot/3.5/reference/features/external-config.html)

## 备份与恢复

在 Linux 上安装与数据库服务端同版本或更新的 PostgreSQL 客户端。为备份账号配置 `PGHOST`、`PGPORT`、`PGDATABASE`、`PGUSER` 和只读访问凭据，密码可由 `PGPASSFILE` 提供。执行时尽量暂停对资料目录的编辑。

```sh
sh ops/backup.sh /srv/learning-materials /srv/backups/assistant
```

脚本校验数据库转储和资料压缩包，两个文件都生成后才发布备份目录。可在专用的 Linux 计划任务中使用相同命令，每日执行。

```cron
0 3 * * * cd /srv/learning-assistant && sh ops/backup.sh /srv/learning-materials /srv/backups/assistant
```

在计划任务环境中加载上述 `PG*` 参数。恢复时先创建启用了 pgvector 的空数据库，将 `database.dump` 用 `pg_restore --exit-on-error --dbname assistant_restore` 导入，再把 `documents.tar.gz` 解压到独立目录。用恢复后的数据库和资料启动独立实例，核对索引、草稿和发送记录，再切换正式运行配置。
