# 邮箱配置

Compose 将设置写入 `.env`。直接运行 JAR 时，将相同变量注入启动环境。应用按 `ASSISTANT_MAIL_MS` 自动收信，默认间隔 60 秒。

## Gmail

开启 Google 两步验证，若账户允许创建应用专用密码，将该密码填入两个凭据变量。[Gmail 邮件客户端帮助](https://support.google.com/mail/answer/7126229) · [Google 应用专用密码](https://support.google.com/accounts/answer/185833)

```dotenv
ASSISTANT_IMAP_HOST=imap.gmail.com
ASSISTANT_IMAP_PORT=993
ASSISTANT_IMAP_TLS=true
ASSISTANT_IMAP_USER=you@gmail.com
ASSISTANT_IMAP_PASSWORD=<应用专用密码>
ASSISTANT_SMTP_HOST=smtp.gmail.com
ASSISTANT_SMTP_PORT=465
ASSISTANT_SMTP_SSL=true
ASSISTANT_SMTP_STARTTLS=false
ASSISTANT_SMTP_AUTH=true
ASSISTANT_SMTP_USER=you@gmail.com
ASSISTANT_SMTP_PASSWORD=<应用专用密码>
ASSISTANT_MAIL_FROM=you@gmail.com
```

## Outlook.com

在 Outlook.com 的「设置 → 邮件 → 转发与 IMAP」启用 IMAP。用已授权的 Microsoft Entra 应用从外部取得支持 IMAP 和 SMTP 的委托访问令牌，填入两个凭据变量。令牌过期前由部署方更新配置并重启。工作或学校邮箱使用组织提供的主机和授权配置。[Outlook.com 邮件服务器设置](https://support.microsoft.com/en-us/outlook/pop-imap-and-smtp-settings-for-outlook-com) · [Microsoft OAuth 协议说明](https://learn.microsoft.com/en-us/exchange/client-developer/legacy-protocols/how-to-authenticate-an-imap-pop-smtp-application-by-using-oauth)

```dotenv
ASSISTANT_IMAP_HOST=outlook.office365.com
ASSISTANT_IMAP_PORT=993
ASSISTANT_IMAP_TLS=true
ASSISTANT_IMAP_AUTH_MECHANISMS=XOAUTH2
ASSISTANT_IMAP_USER=you@outlook.com
ASSISTANT_IMAP_PASSWORD=<访问令牌>
ASSISTANT_SMTP_HOST=smtp-mail.outlook.com
ASSISTANT_SMTP_PORT=587
ASSISTANT_SMTP_SSL=false
ASSISTANT_SMTP_STARTTLS=true
ASSISTANT_SMTP_AUTH=true
ASSISTANT_SMTP_AUTH_MECHANISMS=XOAUTH2
ASSISTANT_SMTP_USER=you@outlook.com
ASSISTANT_SMTP_PASSWORD=<访问令牌>
ASSISTANT_MAIL_FROM=you@outlook.com
```

若服务商保留 SMTP 发件副本，可配置 `ASSISTANT_IMAP_SENT_FOLDER` 为该文件夹的实际 IMAP 名称。发送结果待核对时，应用按 Message-ID 查询该文件夹。
