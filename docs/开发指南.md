# 开发指南

## 调试

准备本地数据库及环境变量。运行 `mvn spring-boot:run` 启动 API，再运行 `npm --prefix frontend run dev`，用 Vite 显示的地址打开网页。Vite 将 `/api` 请求转发到本机 8080。调试时从「任务记录」获取任务 ID，再在应用日志中查找同一编号。[运行说明](../README.md)

## 验收

从项目根目录运行 `mvn test` 和 `npm --prefix frontend test` 执行后端与前端单元测试。先构建网页，再将 `ASSISTANT_TEST_DB_URL`、`ASSISTANT_TEST_DB_USER` 和 `ASSISTANT_TEST_DB_PASSWORD` 设为专用测试数据库，运行 `mvn verify` 执行集成测试。测试用户需能建 schema，数据库需安装 pgvector。测试自动创建临时资料和 GreenMail 邮箱。

运行手机浏览器验收时，在 `frontend` 目录执行 `npx playwright install chromium`，或设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指向本机 Chromium。设置 `ASSISTANT_BROWSER_E2E=1` 后，从项目根目录运行 `mvn verify`。

GitHub Actions 执行以上回归，保存 JAR，构建镜像并运行 Trivy。Dependabot 每周检查 Maven、npm、镜像和 Actions 依赖。本地可运行 `mvn versions:display-dependency-updates` 查看 Maven 更新。

## 数据库升级

`V1__assistant.sql` 是已发布基线。结构调整放入后续递增的 Flyway 迁移，按变更所属模块命名。`V2__task_admission.sql` 包含任务限流索引。升级前备份数据库和资料目录。

## 监控与密钥轮换

`/actuator/health/liveness` 用于进程存活探测，`/actuator/health/readiness` 同时检查 PostgreSQL。登录后通过 `/actuator/metrics` 查看 `http.server.requests` 请求耗时、`assistant.tasks.queued` 队列长度和 `assistant.ai.calls` 模型调用次数与耗时。模型指标会在产生调用后出现。`ASSISTANT_LOG_LEVEL` 和 `ASSISTANT_APP_LOG_LEVEL` 控制 ECS JSON 日志级别。

轮换模型或邮箱凭据时，先准备新凭据，更新环境变量，再重启 JAR 或执行 `docker compose up -d --force-recreate app`。确认就绪探针及对应任务正常后，撤销旧凭据。停止服务时，网页请求和已经开始的后台任务有收尾时间，未完成的任务由持久调度接续。进程中断时已认领的外发遵循[待核对规则](api/mail.md#e03)。
