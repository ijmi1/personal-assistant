## 黑盒验收

Java 端用 JUnit 5，测试路径相对 `src/test/java/assistant/acceptance/`。自动验收通过 HTTP 操作，使用临时资料、启用 pgvector 的 PostgreSQL、可控模型和本地测试邮箱。邮件断言检查收件端的信数与实际内容。C01 用 Playwright 的手机视口执行。正式部署后，用两个本人邮箱和手机完成真机联调。

| 编号 | 测试 | 核对的场景 |
|---|---|---|
| K01 | `KnowledgeIT#syncChanges` | 新增、修改、改名、删除、目录失联、损坏和扫描版 PDF。让旧版索引任务晚于新版完成，再查已删除或修改的原句。 |
| K02 | `KnowledgeIT#answerFromSources` | 一组带标准原段的中文术语、英文标识、改述题和无依据题。核对前五段命中及回答逐条引证，分别记录关键词和混合检索结果。 |
| K03 | `ReaderIT#followCitation` | Markdown 段落与 PDF 页准确。改版后分别构造唯一匹配、重复原句及删除，检查阅读器提示。 |
| K04 | `ReaderIT#resumeAcrossDevices` | PDF 页内中部、Markdown 段落，各用两台设备。引用预览后回到原书签，迟到的旧写入不能覆盖较新记录。 |
| E01 | `MailboxIT#syncThread` | 重复同步、游标失效重扫、关联追问、同主题不同往来。检查收件数及新增拟稿任务数。 |
| E02 | `DraftIT#editAndKeep` | 双击拟稿、跨设备编辑、编辑期间有追问、放弃草稿，核对引用和收件数。 |
| E03 | `DeliveryIT#sendFinalVersion` | 旧预览、同时双击、确认后附件源变化、服务器接受后回执丢失并重启。核对状态、实收正文、附件字节和信数。 |
| M01 | `TaskIT#resumeAfterRestart` | 发起任务、关网页、重启服务，重新登录查同一任务。分别演练成功、失败和继续确认。 |
| C01 | `StudyReplyE2E#replyOnPhone` | 按[组合场景](../个人学习助手-MVP需求文档.md)从第二封来信走到收件端，检查手机草稿恢复与内部引文隔离。 |

优先回归 K03、K04、E01、E03。实现后，按[工程约束](../AGENTS-draft.md)登记实际入口与测试位置。
