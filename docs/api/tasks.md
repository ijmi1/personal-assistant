# 任务与接入接口契约

对应[开发设计](../MVP开发设计.md)。手机、电脑与后台共享业务记录，任务编号在服务重启后仍有效。

## HTTP

所有路径相对 `/api/v1`，旧 `/api` 路径继续使用同一契约。Spring Security 校验本人登录会话和写请求的 CSRF 令牌。未登录返回 401，权限不足返回 403。输入无效返回 400，对象未知返回 404，版本或请求键冲突返回 409。错误体含可读原因。

资料提问和拟稿共享每分钟新建任务额度。同键重试、合并至处理中任务和轮询均无需额度。超限返回 429 和 `Retry-After` 秒数。

HTTP 另设每分钟额度。已登录请求按账户统计，匿名请求和登录尝试按来源地址统计。两个 API 路径共享额度。受保护的 OpenAPI 位于 `/v3/api-docs`，浏览入口为 `/swagger-ui/index.html`。

`POST /client-errors` 接收 `{"kind":"navigation"}` 或 `{"kind":"render"}`，返回 204。仅记录错误类型，不接收报错正文、网址、资料或草稿内容。需要登录与 CSRF 令牌。

`GET /session/csrf` 返回 `{token, headerName}`，登录前后各取一次。`POST /session/login` 接收表单 `username` 和 `password`，成功返回 204 并建立会话。`POST /session/logout` 撤销当前会话。`GET /session` 返回当前用户名。错误体为 `{message, current?}`，涉及过时编辑时 `current` 是当前版本。

写操作注明请求键时，用 `Idempotency-Key` 传值。内部调用传同一参数。服务端按本人、操作与键核对输入。相同请求重用原结果，同键不同输入返回 409。确认发送以“草稿 ID + 确认修订”判重，手机和电脑各点一次仍能识别同一版本。接受后台请求返回 202 及可查询编号。

## M01

`TaskView query(TaskSelector selector)`。例如 `GET /tasks/t7` → 任务类型、当前步骤、状态、结果类型与 ID 或失败原因。集合选择器对应 `GET /tasks`，返回本人任务摘要，按最近更新时间排序。查询只读，可反复轮询。未知编号返回 404。手机重新打开后查询原任务，再按结果类型打开回答、草稿或发送记录。

手机发起资料提问、拟稿和确认分别使用 [K02](knowledge.md#k02)、[E02](mail.md#e02)、[E03](mail.md#e03)。关闭页面不取消任务，页面只在收到保存回执后显示已保存。

## Jobs

任务模块公开 `TaskId submit(JobSpec job, WorkKey key)`，供资料同步、问答、收信和拟稿提交后台工作。JobSpec 含任务类型和持久输入引用，返回稳定任务号。例如 提交文档 d1 的版本 v2 与资料索引配置 p1 → t7。同一工作键和输入重试返回 t7，不匹配返回冲突。任务及调度记录通过接入同一 Spring 事务的数据源一起提交，回滚后均不可见。队列中保留 ID，不复制邮件正文与附件。

编排器按类型调用步骤，持久化排队、运行、完成或失败及结果标识。db-scheduler 检测中断执行后重新领取可重试步骤。按工作键复用已完成结果，达到重试上限显示原因。生成模型调用可能重做，保存前检查任务与版本，使用户只看到一个结果。发送处理单独领取已确认的发送记录。此前已进入发送中的记录按 [E03](mail.md#e03) 核对。
